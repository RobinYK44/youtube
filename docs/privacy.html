Privacy Policy

Last updated: 24 September 2026

1. About Shortsbot

Shortsbot is a personal tool that uploads short videos to its owner's own YouTube channel. It is used only by its owner.

2. Use of YouTube API Services

Shortsbot uses YouTube API Services. By using Shortsbot you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

2b. Use of the TikTok API

Shortsbot can also post the same Shorts to the owner's own TikTok account through the TikTok Content Posting API. It requests the TikTok scopes user.info.basic (to know which account to post to) and video.publish (to post videos). See the TikTok Privacy Policy.

3. Information accessed and collected

Shortsbot requests one Google OAuth permission: https://www.googleapis.com/auth/youtube.upload. It uses this permission only to upload videos, with a title, description and tags, to the signed-in user's own channel. Shortsbot does not read, collect or store any other Google or YouTube account data, such as videos, comments, subscribers or analytics.

4. How information is used, stored and shared

  • The OAuth tokens (Google and TikTok) are stored only on the owner's own computer or server, in local files.
  • Shortsbot keeps a local list of the IDs of the Twitch clips it has used and the IDs of the YouTube videos it uploaded, to avoid duplicates.
  • No information is sold, shared with or disclosed to third parties.
  • Shortsbot does not use cookies and does not place any tracking on devices.

5. Deleting your data and revoking access

  • Access can be revoked at any time through the Google security settings page: https://security.google.com/settings/security/permissions.
  • TikTok access can be revoked in the TikTok app under Settings and privacy → Security → Apps and services.
  • Deleting the local token files and the local data folder removes all data stored by Shortsbot immediately.
  • Stored data is kept only while the tool is in use. If access is revoked, Shortsbot can no longer use the token, and all stored data is deleted within 7 days.

6. Contact

Questions can be sent through GitHub issues.

7. Changes
